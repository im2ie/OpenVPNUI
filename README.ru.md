# OpenVPNUI Mac — Intel

Нативный клиент OpenVPN для Intel Mac с macOS 26 и новее. Интерфейс на русском.
В комплекте: установщик 0.2.1, исходники клиента и службы, тесты, скрипты сборки,
исходники зависимостей и лицензии. Готовых VPN-профилей и клиентских сертификатов нет.

Скачайте установщик со [страницы релиза](https://github.com/im2ie/OpenVPNUI/releases/tag/v0.2.1), затем запустите `/Applications/OpenVPNUI Mac.app` и импортируйте
свой профиль и сертификат. Установка запрашивает права администратора и перезапускает
VPN-службу. Для работы Homebrew не нужен. Подписи компонентов локальные (ad-hoc);
подписи Developer ID Installer и нотариализации Apple нет.

В настройках профиля по умолчанию включена обязательная проверка Split DNS.
Если сервер передаёт только домен поиска без DNS-серверов, задайте DNS-правила
вручную или отключите требование Split DNS, когда VPN DNS вам не нужен.
Автоподключение профиля по умолчанию выключено.

Сборка, функции и технические ограничения описаны в [README.md](README.md).
Проверки подготовленной версии перечислены в [VALIDATION.json](VALIDATION.json).
Локальные скрипты сборки ничего не публикуют. GitHub Actions публикует проверенные
файлы в Releases при отправке тега версии; личные токены и SSH-ключи в проект не входят.
