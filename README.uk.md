# OpenVPNUI Mac

Нативний клієнт для **Intel Mac із macOS 26 або новішою**.

Основна мова інтерфейсу — англійська. Українську можна вибрати в
**Settings and service → General → Language → Українська**.
Вибір зберігається. Якщо у версії 0.2.2 було вибрано російську, після оновлення
автоматично буде вибрано українську. Англійська залишається без змін.
Інтерфейс перемикається без розриву VPN-з’єднання; деякі системні меню й діалоги
macOS змінюють мову після перезапуску програми.

[Завантажити інсталятор 0.2.3](https://github.com/im2ie/OpenVPNUI/releases/download/v0.2.3/OpenVPNUI-Mac-Intel-0.2.3.pkg).
Перед установленням завершіть роботу з VPN і закрийте програму: інсталятор
перезапускає VPN-службу. Наявні профілі зберігаються.
Після встановлення відкрийте `/Applications/OpenVPNUI Mac.app` та імпортуйте
власний профіль і сертифікат. Для роботи Homebrew не потрібен.
Компоненти мають локальні підписи (ad-hoc); підпису Developer ID Installer
і нотаризації Apple немає.

У комплекті: інсталятор, вихідний код клієнта та служби, тести, сценарії збирання,
вихідний код залежностей і ліцензії. Готових корпоративних профілів,
клієнтських сертифікатів і приватних ключів немає.

Політика Split DNS за замовчуванням вимагає коректних доменних правил DNS.
Якщо ваш VPN їх не надає й вони не потрібні, вимкніть цю вимогу в налаштуваннях
профілю. Глобальна заміна DNS не виконується.

Збирання, можливості й обмеження описано в [README.md](README.md).
Перевірки підготовленої версії наведено у [VALIDATION.json](VALIDATION.json).
Локальні сценарії збирання нічого не публікують. GitHub Actions публікує перевірені
файли в Releases після надсилання тегу версії; особисті токени й SSH-ключі
не входять до проєкту.
